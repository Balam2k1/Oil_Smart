TÀI LIỆU KỸ THUẬT GIAO THỨC MODBUS RTU

Thiết bị: Cảm Biến Phiên bản: 1.0 Ngày phát hành: 2026

1. THÔNG SỐ GIAO TIẾP VẬT LÝ

  • Giao diện phần cứng: RS-485 (Half-Duplex)
  • Baud Rate: 9600 bps
  • Data Bits: 8
  • Parity: None
  • Stop Bits: 1
  • Byte Order: Big-Endian (High Byte truyền trước, Low Byte truyền sau)
  • CRC: CRC-16 (Modbus), truyền Low Byte trước, High Byte sau.

2. CẤU TRÚC KHUNG TRUYỀN RAW (MODBUS RTU FRAMES)

Thiết bị hỗ trợ 3 mã lệnh (Function Codes) theo chuẩn Modbus RTU. Dưới đây là cấu trúc byte thô để hỗ trợ lập trình thư viện nhúng trên MCU Master (STM32, PIC, v.v.).

2.1. Lệnh 0x03 - Read Holding Registers

Đọc dữ liệu từ một hoặc nhiều thanh ghi 16-bit liên tiếp. (Số lượng thanh ghi tối đa = 6).

Ghi dữ liệu 16-bit vào một thanh ghi đơn lẻ.

3. PHỤ LỤC: THUẬT TOÁN TÍNH CRC-16 (MÃ C/C++ THAM KHẢO)

Hệ thống sử dụng chuẩn CRC-16/MODBUS (Đa thức 0xA001, Giá trị khởi tạo 0xFFFF). Dưới đây là hàm C/C++ tiêu chuẩn để Master (STM32/PIC) nhúng vào thư viện truyền thông:

#include <stdint.h>

// Hàm tính mã kiểm tra lỗi CRC-16 chuẩn Modbus RTU
// buffer: con trỏ trỏ tới mảng byte cần tính (Ví dụ mảng chứa: [ID, Function, Data...])
// length: số lượng byte trong mảng (Không bao gồm 2 byte CRC ở cuối)
// Trả về: Giá trị CRC 16-bit (Lưu ý: Khi ghép vào mảng truyền đi, Byte Thấp (Lo) gửi trước, Byte Cao (Hi) gửi sau)
uint16_t Modbus_CalculateCRC16(const uint8_t *buffer, uint16_t length) {
    uint16_t crc = 0xFFFF; // Giá trị khởi tạo chuẩn
    
    for (uint16_t pos = 0; pos < length; pos++) {
        crc ^= (uint16_t)buffer[pos]; // XOR byte dữ liệu vào CRC
        
        for (int i = 8; i != 0; i--) { // Lặp qua 8 bit
            if ((crc & 0x0001) != 0) { // Nếu bit ngoài cùng bên phải là 1
                crc >>= 1;             // Dịch phải 1 bit
                crc ^= 0xA001;         // XOR với đa thức tiêu chuẩn
            } else {
                crc >>= 1;             // Chỉ dịch phải 1 bit
            }
        }
    }
    return crc;
}

4. BẢN ĐỒ BỘ NHỚ (MODBUS REGISTER MAP)

Bản đồ bộ nhớ gồm 6 thanh ghi (Registers) 16-bit. Địa chỉ logic bắt đầu từ 0x0000.

Địa chỉ (Hex) Tên Thanh Ghi Quyền Truy Cập Mô Tả Cấu Trúc Dữ Liệu
0x0000 Raw Data Read Only Giá trị đo lường 16-bit tự động thay đổi theo Loại Cảm Biến (Sensor Type ở 0x0003). Chi tiết xem tại Mục 5.
0x0001 Operating Hours Read / Write Tổng số giờ hoạt động (0 - 65535 giờ). Được lưu vào EEPROM không mất khi cúp điện. Master có quyền ghi 0x0000 để xóa bộ đếm sau khi bảo dưỡng định kỳ.
0x0002 Modbus ID Read / Write Địa chỉ thiết bị (ID) trên mạng RS-485. Phạm vi hợp lệ: 1 - 247. Dữ liệu chỉ nằm ở Low Byte. Giá trị mặc định xem Mục 6.
0x0003 Sensor Type OTP Cấu hình phần cứng (Phạm vi 1 - 5). Thanh ghi chỉ cho phép ghi một lần (One-Time Programmable). Các lần ghi tiếp theo sẽ bị từ chối ở cấp độ phần cứng.
0x0004 Serial Number H OTP Nửa Cao (High Word) 16-bit của Mã ngày tháng sản xuất (Epoch Time 32-bit). Chỉ ghi 1 lần.
0x0005 Serial Number L OTP Nửa Thấp (Low Word) 16-bit của Mã ngày tháng sản xuất (Epoch Time 32-bit). Chỉ ghi 1 lần.

5. CẤU TRÚC KIỂU DỮ LIỆU ĐO (RAW DATA FORMAT) TẠI REG 0x0000

Giá trị trả về tại thanh ghi 0x0000 là một số nguyên 16-bit không dấu (Unsigned Integer 16-bit). Ý nghĩa vật lý của giá trị này hoàn toàn phụ thuộc vào cấu hình tại thanh ghi Sensor Type (0x0003).

Loại Cảm Biến (Type) Định dạng Dữ liệu (Raw Data Format) Đơn vị tính
Type 1 (Nhiệt độ) Giá trị ADC 12-bit (0 - 4095). Master cần áp dụng hệ số chuyển đổi điện áp thành nhiệt độ. ADC LSB
Type 2 (Vòng tua) Tần số xung đếm được trong chu kỳ 1 giây. Dữ liệu tự động làm mới sau mỗi giây. Hz (Xung/giây)
Type 3 (Áp suất) Giá trị ADC 12-bit (0 - 4095). Tương tự Cảm biến Nhiệt độ. ADC LSB
Type 4 (Lưu lượng Vào) Tổng số xung tích lũy (Accumulator/Totalizer) từ khi bật nguồn (0 - 65535). Không tự động reset.
Master tính lưu lượng bằng cách: Δ(Xung) = Xung(t) - Xung(t-1). Chú ý xử lý toán học hiện tượng tràn số (Overflow 65535 → 0).		 Tổng Xung (Pulses)
Type 5 (Lưu lượng Ra) Hoạt động tương tự Type 4 (Lưu lượng Vào). Tổng Xung (Pulses)

6. DANH SÁCH THIẾT BỊ MẶC ĐỊNH (FACTORY DEFAULTS)

Hệ thống mặc định xuất xưởng 5 loại thiết bị đã được nạp sẵn Firmware và cấu hình cứng (OTP) theo dải địa chỉ sau. Master lập trình cấu hình Pooling List dựa theo danh sách này:

  • Modbus ID 101: Type 1 (Nhiệt độ)
  • Modbus ID 102: Type 2 (Vòng tua)
  • Modbus ID 103: Type 3 (Áp suất)
  • Modbus ID 104: Type 4 (Lưu lượng Vào)
  • Modbus ID 105: Type 5 (Lưu lượng Ra)
